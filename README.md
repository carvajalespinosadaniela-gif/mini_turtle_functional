# Mini Turtle 🐢

Un paquete sencillo que permite dibujar con texto usando movimientos básicos:
- `adelante(pasos)`
- `abajo(pasos)`
- `reiniciar()`

Este paquete mantiene un estado interno (`posición_x`) para simular dibujos tipo tortuga.
